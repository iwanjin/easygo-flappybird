# 🐱 냥냥 메모리 (Memo Cats)

> 초등학생을 위한 재미있는 카드 매칭 메모리 게임

## 🎮 게임 소개

**냥냥 메모리**는 같은 그림의 카드 2장을 찾아 짝맞추는 클래식 메모리 게임입니다.  
귀여운 동물 이모지와 함께 집중력과 기억력을 단련할 수 있습니다.

- 🌍 **플랫폼**: 웹 브라우저 (PC + 모바일)
- ⚡ **기술**: HTML5 + CSS3 + Vanilla JavaScript
- 💾 **저장**: 브라우저 로컬 저장소 (서버 불필요)
- 🚀 **배포**: GitHub Pages (무료)

---

## 🎯 게임 규칙

### 기본 플레이
1. 게임 시작 시 카드가 뒷면으로 섞여서 배치됩니다
2. 카드 2장을 차례로 클릭하여 뒤집습니다
3. 두 카드의 그림이 **같으면** ✨
   - 매칭 성공! 카드가 앞면으로 고정됨
   - **+100점** 획득
4. 두 카드의 그림이 **다르면** ❌
   - 1초 후 자동으로 다시 뒤집힘
   - **-10점** (최소 0점)
5. 모든 카드를 매칭하면 **🏆 게임 클리어!**

### 난이도별 게임판

| 난이도 | 보드 크기 | 카드 수 | 짝 수 | 제한 시간 | 예상 시간 |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 🟢 **쉬움** | 4×3 | 12장 | 6쌍 | 120초 | 1~2분 |
| 🟡 **보통** | 4×4 | 16장 | 8쌍 | 180초 | 2~4분 |
| 🔴 **어려움** | 4×6 | 24장 | 12쌍 | 240초 | 4~7분 |

### 점수 계산

```
점수 = (매칭 성공 × 100점) + (매칭 실패 × -10점) + (남은 시간 × 2점)
최소 점수 = 0점
```

**예시**:
- 매칭 성공 8회: +800점
- 매칭 실패 2회: -20점
- 남은 시간 30초: +60점
- **최종 점수: 840점** 🎉

## 🎮 플레이 방법

### PC (데스크톱)
1. 마우스로 카드를 클릭합니다
2. 카드가 뒤집혀서 그림을 볼 수 있습니다
3. 다시 클릭해서 카드를 닫거나 다음 카드를 선택합니다

### 모바일 (태블릿/스마트폰)
1. 손가락으로 카드를 탭합니다
2. 카드가 뒤집혀서 그림을 볼 수 있습니다
3. 다시 탭해서 카드를 닫거나 다음 카드를 선택합니다

## 🔧 기술 스택

| 항목 | 기술 |
|:---|:---|
| **HTML** | HTML5 시맨틱 구조 |
| **CSS** | CSS3 애니메이션 + Flexbox 반응형 |
| **JavaScript** | Vanilla JS (프레임워크 없음) |
| **저장소** | LocalStorage (클라이언트 저장) |
| **배포** | GitHub Pages (정적 호스팅) |

### 모듈 구조 (팀 분담)

```
js/
├── game.js         ← 🅰️ A팀 (게임 로직 및 상태 관리)
├── cards.js        ← 🅰️ A팀 (카드 생성 및 셔플)
├── ui.js           ← 🅱️ B팀 (화면 전환 및 이벤트)
├── difficulty.js   ← 🅲 C팀 (난이도 설정값)
├── storage.js      ← 🅲 C팀 (최고점 저장/로드)
├── sound.js        ← 🅲 C팀 (효과음 시스템)
└── confetti.js     ← 🅲 C팀 (승리 파티클)

css/
└── style.css       ← 🅱️ B팀 (전체 스타일)

assets/
└── sounds/         ← 🅲 C팀 (효과음 파일)
```

## 🚀 설치 및 실행

### 로컬에서 실행

```bash
# 1. 저장소 클론
git clone https://github.com/iwanjin/memo-cats.git
```

## 📊 게임 데이터

### 저장되는 정보

- **최고점 (난이도별)**
  - 쉬움: `memoCats_best_easy`
  - 보통: `memoCats_best_medium`
  - 어려움: `memoCats_best_hard`

- **음소거 상태**
  - `memoCats_muted` (true/false)

**저장 위치**: 브라우저 LocalStorage  
**삭제 방법**: 브라우저 캐시/쿠키 삭제 또는 개발자 도구에서 LocalStorage 삭제
